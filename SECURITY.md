# Security Policy

## Reporting a vulnerability

Please report security issues **directly to Bookipi** — do not open a public
GitHub issue for anything security-sensitive.

- **Email:** [support@bookipi.com](mailto:support@bookipi.com)

Include as much of the following as you can:

- What you found and where (CLI command, skill bundle, API endpoint, docs)
- Steps to reproduce
- The version affected (`bookipi --version`, or the release tag)
- Any impact you've observed (e.g. data exposure, credential leakage)

We'll acknowledge your report and keep you updated as we investigate and fix
the issue. Please give us a reasonable window to remediate before disclosing
publicly.

## Scope

This repository distributes the Bookipi CLI and its Claude skill bundle.
Reports about the CLI, the bundle, or the Bookipi services it talks to
(`*.bookipi.com`, `*.bkpi.co`, `*.bookipay.com`) are all welcome at the
address above.

## Supported versions

Only the [latest release](https://github.com/Bookipi-Group/bookipi-agent-cli-release/releases/latest)
is supported. If you're on an older version, please update before reporting.
